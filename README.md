# 🐍 SerpentX

A modern Snake Game built using **HTML**, **CSS**, and **Vanilla JavaScript**.

Unlike traditional implementations, this project features responsive board generation, animated gameplay, bonus food mechanics, persistent high scores, and keyboard controls without using any external libraries.

# 📸 Gameplay

### Game Flow

```
Press Space

↓

↓

Collect Food

↓

Snake Grows

↓

Every 6 Foods

↓

Bonus Food Appears

↓

Increase High Score

↓

Avoid Walls & Yourself
```

# 🧠 Game Mechanics

### Food

- Increases score
- Increases snake length

### Bonus Food

Appears after every 6 food items.

- Gives extra score
- Includes animation
- Makes gameplay more exciting

---

# High Score

The highest score is stored locally using **Local Storage**, allowing players to retain their best score even after refreshing the page.

---

# Responsive Grid

Instead of hardcoding the board size, the game dynamically calculates rows and columns based on the browser window, making it adaptable to different screen sizes.
